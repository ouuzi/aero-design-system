# Logos

- `brand-mark-navy.svg`: the AeroCompetence Hub mark in `color-brand` (#0f2a4a), for light surfaces. In the app it is the `BrandMark` component, which inherits `currentColor`; these files fix the ink because an `<img>` cannot inherit it.
- `brand-mark-accent-soft.svg`: the same mark in `color-accent-soft` (#8db7f5), for navy surfaces such as the sign-in panel.
- `app-icon.svg`: the favicon, the mark in white on a `color-brand` tile with a 7px corner.
- The operator's logo file: used only on printed Part-145 authorisation cards. It is not the product's mark.
