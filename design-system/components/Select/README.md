# Select

The form dropdown: written like a native `<select>`, drawn by the kit. The field is the same box as an Input (surface, `color-line-strong` border, `shadow-xs`, radius lg) with a 16px muted chevron; the list that opens is the floating surface of menus and the Combobox (white, hairline, `shadow-popover`, radius xl) with 32px rows, a tick on the current option and the inset accent outline on the active row.

- **Consumer provides** `<option>` (and `<optgroup>`) children with `value` and `onChange` exactly as on a native select: `onChange` receives a real change event, so `e.target.value` is the picked value. `defaultValue` (uncontrolled), `name`, `required`, `disabled`, `form` and a ref (the native `HTMLSelectElement`) work as before. Children may be fragments, arrays and `{cond && <option>}`; a disabled option shows but cannot be picked, a disabled `optgroup` disables its options.
- **Size**: `lg` 40px in forms (the default), `md` 36px in toolbars, `sm` 32px in table cells; 48, 44 and 40px in comfortable density. `className` sets width and placement on the field (`w-56`, `w-auto`). With `w-auto` the field is as wide as its longest option, as a native select is, so it never jumps when the value changes.
- **Value**: the picked option's text; a long value truncates in the field, list rows wrap. An option with the empty value ("Select a position", "None") is the placeholder and shows muted.
- **In a Field**: `<Field label hint error>` points its label at the field and wires the hint or error (`aria-describedby`, `aria-invalid`); `error` turns it `color-danger`. Without a Field give it an `aria-label`.
- **Keyboard** (select-only combobox): Enter, Space, Up or Down open the list on the current option; typing letters opens it on the first option that starts with them; Up, Down, Home, End, PageUp, PageDown move; typing jumps; Enter or Space picks; Escape closes the list only (a dialog around it stays open) and Tab closes it and moves on. Focus returns to the field.
- **List**: at least as wide as the field and at most 384px, at most nine rows before it scrolls, opening above the field when there is no room below; the current row is scrolled into view. It sits above every dialog layer (Popover, z 80), so it works in `ModalShell` sheets; picking an option never closes the dialog.
- **States**: rest, hover (`color-muted` border), focus and open (accent border and 2px ring, chevron turned over), invalid, disabled (`color-subtle` fill, `color-disabled` text).
- `FilterSelect` is the same dropdown for toolbars, with its label inside the box. For a list to search, or one people add to, use `Combobox`; for an editable status, `StatusSelect`.

How it works: the children go into a visually hidden native select that stays in the form (value, `required` validation, the ref); the field is a `<button role="combobox">` and the list a `role="listbox"`. Picking sets the native select's value and dispatches its `change` event. The listbox behaviour is shared with `StatusSelect` (`useListbox`).
